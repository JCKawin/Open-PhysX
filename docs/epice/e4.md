# E4 — Collision modifier

Points: 3. Epic E. Depends on [E2](e2.md).

Blender spec: `MOD_collision.cc`. One per object (`eModifierTypeFlag_Single`). It does not deform. It marks the object and owns collision settings. The mesh it uses is the result of the modifiers above it.

## What to do

Add a Collision modifier that can appear only once on an object. It stores thickness and the flags a later solver needs. It does not run contacts. It publishes the triangle mesh above it as the collider for this object.

## How to do

1. `ModifierType::Collision` with `float thickness` (default `0.02`) and `bool enabled`.
2. Adding a second one is refused. The status line says it is single. Blender does the same.
3. Evaluation: after the modifiers above it have produced the working mesh, copy that mesh id or the working triangles into `EvaluatedObject::collider`. Modifiers below it do not change the collider. In Blender the collision modifier uses the mesh at its position in the stack. Document that. Place it under the wave in the test so the collider is waved.
4. If the object has no mesh, the collider is the primitive box, triangulated into 12 triangles, in object space.
5. The Physics or Modifiers tab shows thickness. Draw nothing unless the collision overlay from [C4](../epicc/c4.md) is on. Then draw the collider wire in a dim color.

## What to consider

- Collision is not the rigid body shape. Rigid body shape source in Blender can be base, deform, or final. The collision modifier is what cloth and fluid effectors read. [G3](../epicg/g3.md) may read the same triangles. Keep the mesh on `EvaluatedObject` so both can.
- Single-instance is per object, not per scene.
- Thickness is a skin around the surface for later queries. Do not inflate the drawn mesh by thickness unless the overlay is on. The draw of the object stays the evaluated mesh without the skin.

## Output

An object can have one Collision modifier. A second add is rejected. With Wave above it and the overlay on, the wire matches the waved surface, not the rest mesh. The original mesh buffer is unchanged.
