# E2 — Modifier vtable

Points: 3. Epic E. Depends on [E1](e1.md), [B1](../epicb/b1.md), and [D1](../epicd/d1.md).

Blender spec: `ModifierTypeInfo` in `BKE_modifier.hh`. `OnlyDeform` changes positions. `Constructive` returns a new mesh.

## What to do

Evaluate the modifier list into the evaluated mesh. A deform modifier edits a copy of the positions. A constructive modifier returns a new mesh. The original mesh in the library is unchanged. A muted modifier is skipped. `show_viewport` gates the window. `show_render` is ignored until a bake calls the same function with a render flag.

## How to do

1. `src/logic/ModifierEval.h`: a function table keyed by `ModifierType`.
   - `deform(const ModifierHeader&, const Mesh& in, std::vector<Vec3>& positions)`
   - `construct(const ModifierHeader&, const Mesh& in) -> Mesh`
2. The evaluator copies the original mesh into a working mesh, then walks the vector. `None` is a no-op used as a test. Deform types write `positions` only. Construct types replace the working mesh.
3. `EvaluatedObject` holds the working mesh. If no modifier is visible, it holds a reference (mesh id) and does not copy triangles.
4. `eModifierTypeFlag_RequiresOriginalData` equivalent: a bool on the type, `needs_original`. If a later modifier has it and an earlier one was constructive, skip the later one and report "needs original data" on the row. No such modifier exists until you add one. The check is still in the walker.
5. Time-dependent modifiers receive `SimulationState::time`. The walker passes it in. [E3](e3.md) is the first user.

## What to consider

- Copy-on-write matters. A 1-million-triangle mesh with an empty stack must not allocate a second copy every frame. The id reference path is the fast path.
- Normals: after a deform, recompute normals on the working mesh. Do not write them back to the original.
- The vtable lives in `logic/`. The panel only displays names and flags.

## Output

A test modifier of type `None` in the stack leaves the draw identical and leaves the original positions bitwise unchanged. A test deform that adds `(1,0,0)` moves the drawing only. Removing it restores the drawing. Muting `show_viewport` does the same.
