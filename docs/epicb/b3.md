# B3 — Import OBJ and STL

Points: 5. Epic B. Depends on [B1](b1.md) and [B2](b2.md).

Blender spec: `io/wavefront_obj`, `io/stl`, `io/common/IO_orientation.hh`.

## What to do

Import an OBJ or an STL as one new mesh object. Convert axes and units at the boundary so the mesh sits in this project's Y-up, right-handed, meter scene. The original file is not kept as the live mesh.

## How to do

1. Add `src/io/ObjImport.cpp` and `src/io/StlImport.cpp`. They return a `Mesh` plus a transform, or an error string. They do not touch the window.
2. OBJ: read `v` and `f`. Triangulate polygons with a fan around the first vertex. That matches a simple OBJ. Skip `vt` and materials in this story. Negative face indices count from the end, as the OBJ spec does.
3. STL: detect binary (80-byte header, then a triangle count) versus ASCII (`solid` ... `facet`). Read triangles. Weld vertices that are equal within `1e-6` meters so the mesh is not three unique vertices per triangle. Compute normals with the [B1](b1.md) routine. Do not trust STL facet normals as vertex normals.
4. Axis conversion, applied once on positions before they enter `Mesh`:
   - OBJ from Blender is typically Z-up, `-Y` forward. Convert `(x, y, z)` file to `(x, z, -y)` scene so file +Z becomes scene +Y.
   - Document the matrix in the importer and test it with a file that has a vertex at `(0, 0, 1)`. The stored position is `(0, 1, 0)`.
5. Units: if the file has no unit, treat one file unit as one meter. Add a scale factor argument defaulting to `1`. Do not guess inches.
6. File → Import creates one object, names it from the file stem, assigns a new mesh id, selects it, and frames it with the existing `frame_bounds`. One file, one object. An OBJ with several `o` groups still becomes one mesh in this story. Split groups later if needed.

## What to consider

- Y-up is not Blender's Z-up. Forgetting the conversion puts every imported floor on the wrong plane. The `(0,0,1)` test is the check.
- Do not scale the object transform to fit the grid. Frame the view instead. The mesh numbers stay in meters.
- Binary STL is little-endian. ASCII STL is the fallback when the binary triangle count does not match the file size.
- Import is one undo step, like Open. A bad file does not change the scene.
- The importer must not allocate with raylib and must not draw.

## Output

Importing a cube OBJ and a cube STL produces two objects whose bounds match the file after the axis conversion. The `(0,0,1)` vertex test passes. The view frames the new object. Ctrl+Z removes the import.
