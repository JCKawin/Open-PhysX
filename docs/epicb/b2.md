# B2 — Scene file Open and Save

Points: 5. Epic B. Depends on [A5](../epica/a5.md) and [B1](b1.md).

Blender spec: `blenloader` is the `.blend` format. Do not implement that. This story is the workstation file the File menu already promises.

## What to do

Turn File → Open and File → Save from disabled items into real commands. The file stores the scene version, objects, parents, component slots, and meshes. It does not store the playhead as a required field, and it does not store viewport camera state unless you add it explicitly. It is not a `.blend`.

## How to do

1. Add `src/io/`. `logic/` may call it. `io/` may not include raylib or ImGui. The File menu in `Workspace` calls `save(path)` and `load(path)`.
2. Use a versioned chunk format. First four bytes are a magic (`OPXS`), then `uint32` version from `Scene::version`. Each chunk is a type tag, a byte length, and the payload. Unknown chunks are skipped so a newer file fails cleanly on an older build only when the version is too new, not when a chunk is extra.
3. Write objects, then meshes. Object fields reference mesh ids. On load, reject a mesh id that was not in the file.
4. Paths: Save writes the current path if there is one, otherwise ask with a native dialog or a simple path field. Open replaces the scene and pushes one full undo step so the user can undo the open.
5. Enable the menu items. Ctrl+`S` saves. Ctrl+Shift+`S` is Save As. Ctrl+`O` opens. These chords must not fire while ImGui wants text input, same as the rest of the keymap.
6. Round-trip test: build a scene with two objects, one parented, one with a mesh, save, load into an empty scene, and compare ids, names, transforms, and index counts.

## What to consider

- Do not write evaluated meshes, caches, or solver bodies. Those are rebuilt. [G6](../epicg/g6.md) and [H3](../epich/h3.md) are separate files on disk.
- Floats are little-endian IEEE. Document that in the chunk header. This project builds on Windows first.
- A failed load leaves the previous scene in place and reports the reason in the status line. Do not clear the scene and then fail.
- Names are UTF-8. Length-prefix them. Do not use `std::string` layout on disk.

## Output

File → Save writes a file. File → Open restores objects, parenting, selection can be cleared on load (Blender clears operator state; restoring selection is optional). Ctrl+Z after Open returns the previous scene. The menu items are enabled.
