# B1 — Mesh component

Points: 5. Epic B. Depends on [A3](../epica/a3.md).

Blender spec: `BKE_mesh.hh`, `DNA_mesh_types.h`. Positions and faces are custom-data layers. For this story a triangle list is enough.

## What to do

Store a mesh as positions, triangle indices, and vertex normals. The object's mesh slot holds an id into a mesh library on the scene. Modifiers, when they exist, read this mesh and write a different one. They never write the original.

## How to do

1. Add `src/core/Mesh.h`. `Mesh` has `std::vector<Vec3> positions`, `std::vector<uint32_t> indices` (three per triangle), and `std::vector<Vec3> normals` (one per vertex, or one per corner if you pick that and stick to it). Vertex normals are the right first choice.
2. `Scene` owns `std::vector<Mesh>` plus the same id counter rule as objects. `Object::mesh_id == 0` means no mesh. The box primitive stays valid with no mesh.
3. Normals are computed once at creation: accumulate face normals into vertices, then normalize. Store them. Do not recompute every frame.
4. The renderer draws the mesh when `mesh_id` is set, using the object's world matrix. It draws the box when the slot is empty. Wire and solid can both use the same triangles. Shading modes are [C4](../epicc/c4.md).
5. Add one built-in mesh, a cube matching the current box size, assigned to object 0 only behind a flag or a Shift+`A` choice. Keep the primitive box path so the demo does not depend on mesh code to boot.
6. Put the mesh library in the undo snapshot from [A5](../epica/a5.md). Editing positions is not in this story. Sharing an id between two objects is allowed and means they share the original mesh.

## What to consider

- Y-up, right-handed. A mesh built here has +Y up. Imported files are converted in [B3](b3.md), not here.
- Winding is counter-clockwise when looking against the normal. The cube's outside faces must face out. Pick one test cube and check six normals point away from the center.
- Do not store a simulated or deformed copy in `Mesh`. That copy is the evaluated mesh in [E2](../epice/e2.md).
- `logic/` and `core/` stay free of raylib. The renderer converts `Vec3` to `Vector3` at the draw call.
- Large meshes must not be copied into the undo stack on every transform. Undo of a transform copies object transforms. Undo of a mesh edit, later, copies the mesh. This story only needs the library in the scene snapshot taken on duplicate and delete.

## Output

Object 0 can display a triangle cube that matches the old box. A second object with no mesh still draws the primitive. Normals on the test cube point outward. The original arrays are not written by the renderer.
