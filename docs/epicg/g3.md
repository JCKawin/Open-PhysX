# G3 — Rigid body settings and shapes

Points: 5. Epic G. Depends on [G2](g2.md), [E4](../epice/e4.md) for the final mesh, and [B1](../epicb/b1.md) for triangle data.

Blender spec: `RigidBodyOb` in `DNA_rigidbody_types.h`. Types `RBO_TYPE_ACTIVE` and `RBO_TYPE_PASSIVE`. Shapes `RB_SHAPE_BOX`, `SPHERE`, `CONVEXH`, `TRIMESH`. Flags for kinematic, deactivation, axis locks.

## What to do

An object can become a rigid body. The user sets active or passive, kinematic, mass, friction, restitution, damping, sleep thresholds, and axis locks. The collision shape is a box, a sphere, a convex hull, or a triangle mesh taken from the evaluated mesh. Changing the mesh marks the shape dirty. No contacts run.

## How to do

1. Fill `RigidBodySettings` from the empty slot in [A3](../epica/a3.md):
   - `enum class BodyKind { Active, Passive }`
   - `bool kinematic`, `bool can_sleep`, `bool start_asleep`
   - `float mass` (default `1`, ignored when passive), `friction` `0.5`, `restitution` `0`
   - `float linear_damping`, `angular_damping` default `0.04` and `0.1` to match Blender's typical panel defaults if you check `DNA` init. If you do not look them up, use `0.1` and `0.1` and say so.
   - `Vec3 linear_factor`, `angular_factor` default `1,1,1`. A `0` locks that axis.
   - `enum class Shape { Box, Sphere, ConvexHull, TriangleMesh }`
   - `bool shape_dirty`
2. Box uses the primitive size or the mesh bounds. Sphere uses the bounding sphere. Convex hull and triangle mesh read `EvaluatedObject::collider` or the evaluated mesh. Triangle mesh is for passive bodies first. Active triangle meshes are concave and do not belong in the first contact story. Refuse active plus triangle mesh with a status line. Blender allows it and then fights the solver. Do not.
3. Physics tab, object section, when the active object has a rigid body. A button adds and removes it. Add sets `shape_dirty`.
4. Build the runtime shape into pool storage from [G1](g1.md) when dirty: box extents, sphere radius, or a copied triangle list. Rewind does not free the pool. The shape lives until the rigid body is removed or the mesh changes.
5. Overlay from [C4](../epicc/c4.md) draws the shape wire when enabled.

## What to consider

- Passive means the animation and constraints drive the transform. Active means the solver will. Kinematic is an active body driven by the animation for that frame. Store the flag even though [G4](g4.md) is the first user.
- Mass `0` is invalid for an active dynamic body. Clamp to a small epsilon or switch to passive. Blender uses mass and also derives it from volume. A direct mass field is enough.
- Shape rebuild is not a per-frame copy. Only on dirty. Wave on a triangle-mesh body dirties every frame. That is acceptable for a wave, and it is why the flag exists.

## Output

The user can mark the cube active with a box shape and a second object passive with a mesh shape. The overlay draws both. Removing the rigid body clears the shape. An active triangle mesh is refused. The cube still does not fall.
