# F2 — Child Of and copy transforms

Points: 3. Epic F. Depends on [F1](f1.md) and [D1](../epicd/d1.md).

Blender spec: `CONSTRAINT_TYPE_CHILDOF`, `LOCLIKE`, `ROTLIKE`, `SIZELIKE` in `source/blender/blenkernel/intern/constraint.cc`.

## What to do

Evaluate four constraint types onto the object's world matrix, in list order, each blended by influence. Child Of parents the matrix to the target. Copy Location, Copy Rotation, and Copy Scale copy those channels from the target. Mute or influence 0 skips the row.

## How to do

1. Represent the working transform as a matrix or as location, quaternion, and scale. Stay with location, quaternion, and scale if the rest of the app does. Blender mixes matrices. Either is fine if every type uses the same one.
2. Child Of: `world = target_world * local`. Blend with influence by nlerping location and scale and slerping rotation toward that result. Inverse of the target at the moment the constraint is added is the "set inverse" Blender uses so the object does not jump. Store that inverse on the payload when the user presses Set Inverse, and also when the constraint is created.
3. Copy Location: replace location channels. A bool per axis, default all on. Blend: `loc = lerp(before, copied, influence)`.
4. Copy Rotation: slerp quaternion toward the target quaternion by influence. Per-axis booleans can wait. All axes on is the first version.
5. Copy Scale: lerp scale the same way as location.
6. Order is the list order. The output of row `i` is the input of row `i+1`. Targets are read from their authored world matrix before this object's constraints, or from an already evaluated target if you evaluate parents first. Evaluate in hierarchy order: parent before child. Constraints that target an unrelated object read that object's matrix from this same pass if it was earlier, otherwise its parented matrix without constraints. Document the pass as "one sweep in scene order after parents". A cycle of constraints (A copies B, B copies A) uses the previous frame's result for the back edge. Detect the cycle and say so on the row. Do not recurse forever.

## What to consider

- Set Inverse is the difference between a useful Child Of and an object that snaps to the target origin. Without it the story is wrong even if the math is right.
- Influence is not a mute. `0.5` is a halfway blend.
- Copy constraints do not create a parent. The outliner parent and Child Of can both exist. Apply the outliner parent first ([D1](../epicd/d1.md)), then the stack.
- A missing target skips the row and leaves the matrix unchanged.

## Output

A cube with Child Of to a second cube follows it when the second moves, and does not jump on the frame the constraint is added. Copy Location at influence `1` matches the target location. Influence `0` leaves the owner where it was. Ctrl+Z removes the constraint and the owner stays at its authored transform.
