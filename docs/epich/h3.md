# H3 — OpenVDB cache

Points: 5. Epic H. Depends on [H2](h2.md).

Blender spec: fluid domain cache, `eFluidDomain_FileFormat` OpenVDB, `BKE_fluid_cache_free`. Blender writes one `.vdb` set per frame for density and velocity. This is the VDB cache. It is not the rigid point cache from [G6](../epicg/g6.md).

## What to do

After each gas step, write density and velocity to a `.vdb` file for that frame. On a cache hit, load the grids and skip the step. Scrubbing reads files. Changing resolution, a flow, or the domain bounds deletes the cache from that frame forward.

## How to do

1. Directory: `<scene>_physics/fluid/frame_00001.vdb`. One file, two grids named `density` and `velocity`. Velocity is a `Vec3` grid.
2. Use OpenVDB if the build can take the library. If the dependency is too heavy for this story, write a tiny documented volume file with the same names and a `.vdb` path reserved, and say in the panel which format is actually on disk. Prefer real OpenVDB. Blender's gas cache is `.vdb`. A private format does not satisfy this story unless the panel says "internal" and a follow-up converts it. Do not label a private format as VDB.
3. Read path: if the file exists and the cache is not outdated, load into the domain grids and skip [H2](h2.md).
4. Outdated: same rule as the point cache. Resolution, time scale, flow settings, effector settings, and domain transform changes set `outdated_from` and delete later frames.
5. Free cache is a button. It deletes the fluid folder and the RAM grids. It does not delete `<scene>_physics/rigid/`.
6. Bake runs forward to `duration` and writes each file, with Esc to stop, same as [G6](../epicg/g6.md).

## What to consider

- OpenVDB's license is MPL, which is fine beside GPL for a library. Do not copy Blender's Mantaflow writers.
- Failed writes leave the previous frame intact and mark the cache outdated so the next play does not trust a half file.
- Loading a `.vdb` from another tool is not required. The files this app writes must load back in this app.
- Do not store the gas grids in the scene file from [B2](../epicb/b2.md).

## Output

Play writes `frame_00001.vdb` and the following frames. Scrubbing back shows the same density in a sample cell without running the Jacobi loop. Changing resolution deletes later frames. Free cache empties the fluid folder and leaves the rigid cache in place.
