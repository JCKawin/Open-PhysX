# H4 — Draw the grid and query velocity

Points: 3. Epic H. Depends on [H2](h2.md) and [H3](h3.md).

Blender spec: `BKE_fluid_get_velocity_at`. The viewport smoke draw in Blender is a shader. This story is a debug draw, not a volume renderer.

## What to do

When the cache overlay is on, draw the gas as points or small boxes colored by density. Provide `velocity_at(position)` that returns density and velocity in world space, or a miss when the point is outside the domain.

## How to do

1. `FluidField sample_domain(const Domain&, Vec3 world_position)` in `logic/`. It maps the position to a cell, trilinear-samples density and velocity, and returns `bool inside`. Outside returns density `-1` or a bool, and zero velocity. Blender returns `-1` density outside. Match that so the call looks like `BKE_fluid_get_velocity_at`.
2. The renderer asks for a list of cells above a density threshold (default `0.05`) or it walks the grid itself from the snapshot. Prefer a compact list built at the end of the gas step: position and density. Cap the list at one point per occupied cell. Do not emit empty cells.
3. Draw points in the viewport when the cache overlay from [C4](../epicc/c4.md) is on. Color from gray at 0 to the accent color at density 1. This is debug. Do not add a ray march.
4. The list is part of the published snapshot so scrubbing a cached frame draws the loaded grid, not a stale list from the last simulate.
5. A test places a point inside the inflow after one frame and expects `inside` and density `> 0`. A point outside the domain expects not inside.

## What to consider

- Sampling must use the same index formula as [H2](h2.md). A mismatch draws the puff in the wrong corner.
- Do not query the solver from ImGui during a bake write. Read the snapshot.
- Point draw of a 32³ grid is at most 32768 points. That is fine. Do not build a point for every empty cell.

## Output

With the overlay on, play shows a colored puff at the inflow that matches the cells `velocity_at` reports. Scrubbing a cached frame shows the same puff. A point outside the domain returns outside. The rigid-body overlay still works on its own toggle.
