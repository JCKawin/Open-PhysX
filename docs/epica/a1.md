# A1 — Scene owns the objects

Points: 3. Epic A. Depends on nothing else in this path. The viewport shell in `src/` is the starting point.

Blender spec: `DNA_object_types.h` (`Object` lives in a scene), `BKE_main` (the database), `BKE_scene`.

## What to do

Replace the single hardcoded cube with a scene that owns a list of objects and one active object. Object 0 is the cube that exists today. `SimulationState` stays the transport and display block: time, playback, grid, clear color, demo motion. It stops being the place the cube lives.

## How to do

1. Add `src/core/Object.h` and `src/core/Scene.h`. `Scene` holds `std::vector<Object>` and `active` as an index. `Object` starts with the fields the cube already has: position, size, rotation, color, visible, selected. Stable id and parent land in [A2](a2.md).
2. `Simulation` owns the `Scene` by value, next to `SimulationState`. `reset()` rebuilds one object at the current cube defaults and sets `active` to 0.
3. Point `visual_body()`, the properties panel, and `G` / `R` / `S` at the active object. Delete `SimulationState::cube`, `cube_visible`, and `cube_selected` once every reader uses the scene.
4. The renderer draws every visible object, not only `visual_body()`. Keep `visual_body()` as the active object's draw pose so the demo sine still offsets that one body and does not write the offset back into the authored position.
5. Extend the undo snapshot in `src/ui/Editor.cpp` so a pose edit stores the active object's transform. Copying `SimulationState` alone will no longer see the cube.

`logic/` includes only `core/`. No raylib, no ImGui.

## What to consider

- Undo today copies `SimulationState` by value. If the scene is a separate object and undo forgets it, Ctrl+Z appears to work and changes nothing.
- `demo_motion` must keep writing the draw pose only. The properties panel shows the authored position.
- Do not introduce a third-party entity framework. The object list is the database.
- One active object is enough. Multi-select comes with [A2](a2.md) and [A4](a4.md).

## Output

Reset shows the same blue cube. Moving it, undoing, hiding, and the demo sine still behave as they do now. A second object can be pushed into the scene from code and both draw. The properties panel edits the active one.
