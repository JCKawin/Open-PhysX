# A3 — Component slots

Points: 2. Epic A. Depends on [A2](a2.md).

Blender spec: `Object.data` (mesh), `Object.rigidbody`, `Object.constraints`, `Object.modifiers`, fluid settings on the fluid modifier. Rigid body is not a modifier.

## What to do

Hang five empty slots on each object: mesh, rigid body, constraints, modifiers, fluid role. Nothing evaluates them yet. The slots exist so later epics fill them without reshaping `Object` again.

## How to do

1. Add the types in `src/core/`, as plain data, not virtual solvers.
   - `MeshSlot`: id of a mesh, or empty. The mesh bytes themselves wait for [B1](../epicb/b1.md).
   - `RigidBodySettings`: present or absent. No fields beyond `bool present` until [G3](../epicg/g3.md).
   - `ConstraintStack`: an empty list. Header fields arrive in [F1](../epicf/f1.md).
   - `ModifierStack`: an empty list. Header fields arrive in [E1](../epice/e1.md).
   - `FluidRole`: `None`, `Domain`, `Flow`, or `Effector`. Default `None`.
2. A new object from Shift+`A` has every slot empty and `FluidRole::None`. Object 0 stays a box with no mesh.
3. Do not put a `step()` method on these types. Evaluation order is [D1](../epicd/d1.md).
4. Duplication in [A5](a5.md) will copy the slots by value. Keep them copyable. No raw owning pointers.

## What to consider

- Blender stores fluid on a modifier and rigid body on the object. Copy that split. Do not invent a `PhysicsComponent` that owns both.
- An empty list and a missing stack are different in Blender (the list exists and is empty). Use an empty list, not a null stack, so the UI can show "no modifiers" without a special case.
- These structs will be saved in [B2](../epicb/b2.md). Fields added later need a version number on the scene. Put `uint32_t version` on `Scene` now, starting at 1.

## Output

Every object reports empty mesh, rigid body, constraints, modifiers, and fluid role. The viewport is unchanged. A unit-style check or a debugger view shows object 0's slots empty and the scene version at 1.
