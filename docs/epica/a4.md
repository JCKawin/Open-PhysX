# A4 — Outliner

Points: 3. Epic A. Depends on [A2](a2.md). [A3](a3.md) can land before or after. The panel only needs id, name, visibility, selection, and parent.

Blender spec: the Outliner (`editors/space_outliner`).

## What to do

Add an Outliner panel. Each row is an object: name, visibility, selection, parent name. Clicking a row selects it. `A` and box select in the viewport use the same selection set.

## How to do

1. Add the panel in `src/ui/Workspace.cpp`, docked as a tab on the existing right column or as its own split. Follow the current panel style. Do not add a new toolkit.
2. List objects in scene order. Indent a row when `parent_id` is set. Show the parent name in the row.
3. An eye toggle writes `visible`. A click sets `selected` and `active`. Shift-click adds or removes from the set. The active row is drawn with the accent color `#E89E3E`.
4. Viewport click and box select, already in `Editor`, must hit every visible object, not the old single cube. Project each object's bounds with `view_project` and test the cursor the way the cube test works today.
5. `A` selects all visible objects. Alt+`A`, or `A` twice if you match Blender's toggle, clears the set. Pick one and document it in the status line. Blender's `A` toggles all.

## What to consider

- The outliner must not call `step()`. It writes the scene. Undo of a selection change is optional here. [A5](a5.md) decides which edits are commands. A visibility click should be undoable, because hide already is.
- Hidden objects are skipped by the viewport hit test and still listed in the outliner.
- Do not draw children of a hidden parent as if they were free in the world. If the parent is hidden, children are hidden too. That matches Blender's viewport.
- Renaming in the outliner can wait. The name is shown. Editing the name is a single `ImGui::InputText` if it falls out cheaply. It must keep names unique.

## Output

The outliner lists every object. Clicking a row makes it active. Shift-click builds a multi-selection. Box select in the viewport matches the outliner. The eye hides an object and Ctrl+Z shows it again.
