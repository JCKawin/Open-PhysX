# A2 — Identity, transform, selection

Points: 3. Epic A. Depends on [A1](a1.md).

Blender spec: `Object.id`, `Object.loc` / `rot` / `scale`, `Object.parent`, `Object.visibility_flag`, selection in the view layer.

## What to do

Give every object a stable id, a unique name, a full transform, visibility, a selection flag, and a parent id. Selection becomes a set of objects. The active object is one member of that set, as in Blender.

## How to do

1. On `Object` add `uint32_t id`, `std::string name`, `Vec3 scale` (default `1,1,1`), `bool visible`, `bool selected`, and `uint32_t parent_id` (`0` means none). Keep location and quaternion from A1.
2. `Scene` mints ids from a counter that only goes up. Deleting an object does not reuse an id. Names are `Cube`, `Cube.001`, matching Blender's suffix rule.
3. Scale is the object's scale. The old `size` field stays as the box dimensions until [B1](../epicb/b1.md) replaces the box with a mesh. Do not overload scale to mean both.
4. Parent is an id, not a pointer, so undo and file save can copy the scene without fixing addresses.
5. `A` selects every visible object. Click in the outliner or viewport replaces the set unless Shift is held. The active object is the last one added to the set.
6. `G` / `R` / `S` apply to every selected object. The modal stores one before-transform per selected id.

## What to consider

- A parent cycle (`A` parents `B` parents `A`) must be rejected when the parent is assigned, not discovered later in the solver.
- Drawing uses the world matrix: parent world matrix times local matrix. Until constraints exist, that product is the whole transform.
- Quaternion rotation stays. Do not store the authored rotation as Euler. Euler in the properties panel is a view of the quaternion, which the panel already does for the cube.
- Ids must survive undo. Restoring a deleted object restores its id. The counter never moves backward.

## Output

Two cubes can be selected together and moved with `G`. Parenting one to the other in data makes the child follow. Names stay unique. Undo restores both transforms and the old selection.
