# A5 — Duplicate, delete, undo

Points: 2. Epic A. Depends on [A1](a1.md), [A2](a2.md), and [A4](a4.md).

Blender spec: `object.duplicate_move` (Shift+`D`), `object.delete` (`X`), `object.hide_view_set` (`H`).

## What to do

Shift+`D`, `X`, and `H` operate on the selection. Undo and redo restore the object list, not one cube. The last object cannot be required to exist. An empty scene draws the grid only.

## How to do

1. Change `Editor`'s history from a copy of `SimulationState` to a copy of `Scene` plus the transport fields that are actual edits (grid, clear color, demo motion). Keep time and `playing` out of edit undo, as the editor does today, except for a full reset.
2. Shift+`D` copies each selected object, assigns a new id and a `.001` name, selects the copies, and deselects the sources. The copies start at the same transform. The existing move modal then runs, matching Blender's duplicate-and-move.
3. `X` and Delete remove the selected objects. Children of a deleted parent get `parent_id = 0`. They are not deleted with the parent.
4. `H` sets `visible = false` on the selection. Alt+`H` sets `visible = true` on every hidden object.
5. Reset Simulation rebuilds the default one-object scene and is one full undo step, including the playhead, as reset is today.
6. Wire the same actions to the outliner context or to buttons only if a button already exists. The keys are the contract.

## What to consider

- Duplicating must copy component slots by value ([A3](a3.md)). Later, mesh data is shared by id until the user makes it single-user. For now there is no mesh, so a value copy is the whole story.
- Do not reuse ids. The undo stack may still hold the old object.
- History stores whole scenes. That is fine at tens of objects. Cap the stack at 64, which the editor already does.
- `G` / `R` / `S` on an empty selection does nothing. Do not create an object as a side effect.

## Output

Shift+`D` makes a second cube and starts a move. `X` removes the selection. Ctrl+Z puts the objects back with the same ids. Hide and show follow the selection. Reset still returns to one cube and can itself be undone.
