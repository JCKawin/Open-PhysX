# C3 — Property tabs

Points: 3. Epic C. Depends on [A3](../epica/a3.md). The tabs can be empty. Later epics fill them.

Blender spec: the Properties editor tabs. The order used here is Object, Modifiers, Constraints, Physics.

## What to do

Split the Properties panel into four tabs in that order. Object holds the fields the panel shows today. The other three show an empty state that names the epic that will fill them. There is one tab bar, not four floating panels.

## How to do

1. In `draw_properties`, add a row of four buttons. Store the open tab on `Workspace`. Default it to Object.
2. Object tab: name, transform (location, Euler view of the quaternion, scale), size for a box primitive, color, visible, selected. These already exist. Move them under the tab. They still arm the undo snapshot on deactivate.
3. Modifiers tab: the text "No modifiers" until [E1](../epice/e1.md). Do not draw a fake modifier.
4. Constraints tab: "No constraints" until [F1](../epicf/f1.md).
5. Physics tab: "No rigid body" and the fluid role `None` until [G3](../epicg/g3.md) and [H1](../epich/h1.md). Showing the `FluidRole` enum as a disabled label is fine if [A3](../epica/a3.md) has landed.
6. World and camera blocks stay under the Object tab or a fifth small section below the tabs. Do not hide the camera FOV. It is not a physics property.

## What to consider

- Tab state is UI state. It is not saved in the scene file.
- Do not duplicate the transform widgets on the Physics tab. Blender's physics panel does not edit location. Location stays on Object.
- Empty states are one line plus the story id, so a reader of the running app knows the tab is waiting, not broken.

## Output

The Properties panel opens on Object and edits the active object. Modifiers, Constraints, and Physics switch without changing the scene. Undo still records a location drag from the Object tab.
