# C4 — Shading and overlays

Points: 2. Epic C. Depends on [B1](../epicb/b1.md) for wire and solid on a mesh. The box primitive can do all three modes without a mesh.

Blender spec: `View3DShading.type` (`OB_BOUNDBOX`, `OB_WIRE`, `OB_SOLID`). Overlay toggles in the viewport header.

## What to do

Add a shading mode: Bounds, Wire, Solid. Add overlay toggles for the grid, the gizmo, and two switches that stay off until later: collision shapes, cache. Solid is the default and matches the current draw.

## How to do

1. Store `enum class Shading { Bounds, Wire, Solid }` and the overlay bools on `SimulationState` or on the editor if they are view-only. Grid is already `show_grid` on the state. Keep it there. Shading can live on the state so it is per scene, or on the editor so it is per view. Prefer the editor. Shading is how you look, not a property of the cube.
2. Bounds: draw the world-axis box of the object (primitive size, or mesh bounds). No filled triangles.
3. Wire: draw edges. For a triangle mesh, draw each triangle's three edges once. A hash of the undirected edge, or a simple index pair set built when the mesh is created, avoids drawing every edge twice. For the primitive, `DrawCubeWires` is the wire.
4. Solid: the current filled cube or filled mesh, plus the selection wire.
5. Viewport corner or the existing Tools panel: three shading buttons and the overlay checkboxes. Gizmo toggle hides [C1](c1.md) handles and does not disable `G` / `R` / `S`.
6. Collision and cache checkboxes exist, default off, and draw nothing until [G3](../epicg/g3.md) and [G6](../epicg/g6.md). Label them so that is obvious.

## What to consider

- Wireframe over a dense mesh can be slow if every edge is a separate draw call. Batch the lines into one vertex list per object. Do not call `DrawLine3D` per edge for a 100k-triangle mesh.
- Selection is still a wire in the accent color, drawn on top of all three modes.
- Bounds of a parented mesh use the world matrix. Axis-aligned bounds in world space are acceptable for this story. Oriented bounds can wait.

## Output

The same cube can be shown as a box outline, a wire cube, or a solid cube. Turning the gizmo overlay off hides the handles. Grid toggle still works. Collision and cache toggles are visible and draw nothing.
