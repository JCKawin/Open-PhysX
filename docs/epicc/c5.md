# C5 — Status text

Points: 1. Epic C. Depends on [C1](c1.md) and [C2](c2.md).

Blender spec: the viewport header and the status bar during a modal operator.

## What to do

Show one status line in the viewport: object mode, the active tool, the orientation, and the gizmo or modal axis. Object mode is the only mode. Do not add an Edit mode entry point that does nothing.

## How to do

1. Extend `Editor::status_line` or the viewport overlay that already prints the nav help.
2. Idle text: `Object | Move | Global`. Swap the tool and the orientation as they change.
3. During `G` / `R` / `S` or a gizmo drag, replace that line with the modal line that already exists (axis, typed number, confirm, cancel) and append `Global` or `Local`.
4. Do not print "Edit mode" and do not bind Tab to a mode switch yet. Tab stays unused or documented as reserved. Mesh edit mode is after the caches, listed at the bottom of [engine-path.md](../engine-path.md).

## What to consider

- Two lines already show FPS and the mouse help. The status line is a third line, or it replaces the mouse help while a modal is active. Do not cover the cube with a paragraph.
- The line is UI. It reads editor state. It does not read the solver.

## Output

The viewport shows `Object | Select | Global` at rest. Starting a move on local X changes the line to the move modal with `Local X`. Cancelling returns the idle line. Tab does not enter a fake edit mode.
