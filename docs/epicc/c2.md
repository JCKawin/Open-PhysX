# C2 — Global and local orientation

Points: 2. Epic C. Depends on [C1](c1.md).

Blender spec: transform orientations. Global is world axes. Local is the object's quaternion. The comma or the orientation menu switches them. Use a toggle in the viewport header or the Tools panel. Do not invent a new chord that steals `G` / `R` / `S`.

## What to do

The gizmo and the axis lock (`X`, `Y`, `Z`, and the second press) share one orientation: Global or Local. Ctrl still snaps. A constrained drag follows the gizmo axis the user grabbed.

## How to do

1. Store `enum class Orientation { Global, Local }` on the editor, default Global. A Tools panel toggle sets it.
2. Global axes are `(1,0,0)`, `(0,1,0)`, `(0,0,1)`. Local axes are `quat_rotate(object.rotation, axis)`. If the object has a parent, local means the object's own quaternion, not the parent. That matches Blender's local orientation.
3. The second press of `X` during a modal already means local in `Editor`. Make the gizmo use that same flag when the orientation is Local, and keep the double-press as an override during the modal.
4. Snap stays in `Editor::apply_transform`: grid for move, 15 degrees for rotate, 0.1 for scale. The gizmo does not snap on its own.
5. The grabbed axis is the constraint for the whole drag. Changing the Tools toggle mid-drag does not retarget the axis. The next drag uses the new orientation.

## What to consider

- A parented object's world axes and local axes differ. Test with a child rotated 90 degrees on Y. Local X must point along the child's right, not the world's.
- Snapping a local-axis move still snaps the distance along that axis, not the world components. The editor already does this when `local_axis_` is set. Reuse it.
- Camera orientation is not a third mode in this story. Blender has View orientation. Leave it out so the toggle stays two states.

## Output

With Local on, a cube rotated 90 degrees shows its move arrow along its own axes. Dragging that arrow changes the local axis only. Ctrl during the drag snaps. Global puts the arrows back on the world axes.
