About

Welcome to Open-PhysX, a physics workstation built on the Blender source tree. It is for simulation, modeling, rigging, animation, rendering, compositing, motion tracking, and video editing. Open-PhysX is available for Linux, macOS and Windows.

Open-PhysX can be used freely for any purpose, including commercial use and distribution. It's free and open-source software, released under the GNU GPL licence, and derived from Blender. Copyright in the original Blender code remains with the Blender Authors and the Blender Foundation.

Although this is considered a stable release, you may encounter a bug. If you do, please help us by posting it in the bug tracker or using Help → Report a Bug from inside Open-PhysX. If it wasn’t reported yet, please log in (or register) and fill in detailed information about the error. Please post detailed instructions on how to reproduce it or post a .blend file showcasing the bug.


Package Contents

The downloaded Open-PhysX package includes:

• The Open-PhysX application for the chosen operating system.

• Add-ons to extend Open-PhysX functionality.

• Readme and copyright files.


Installation

Windows: The download .zip contains an Open-PhysX folder. You may put this anywhere on your hard drive. To launch Open-PhysX, double-click on open-physx.exe.

Linux: Unpack the archive, then run the open-physx executable.

macOS: The downloaded package includes the Open-PhysX app bundle. Optionally copy this to your Applications folder, and add it to the dock by dragging it from there to the dock.


Installing Addons (all systems) Addons can be installed from the user preferences addons section, download an addon as a .py or .zip file, then press the "Install Addon" button and select the file to install it.
